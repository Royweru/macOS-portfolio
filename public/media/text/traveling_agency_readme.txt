# Adventures

**A website for a luxury safari and travel agency.**

The brief was feel over feature count. Adventures is image-led, restrained in its typography, and built so nothing stands between the visitor and the destination.

---

## Links

- **Source code:** https://github.com/Royweru/adventures-travel-luxury
- **Demo video:** on the project folder

## Tech stack

- Next.js
- TypeScript

## Run it locally

```bash
git clone https://github.com/Royweru/adventures-travel-luxury.git
cd adventures-travel-luxury
npm install
npm run dev
```

Then open `http://localhost:3000`.
