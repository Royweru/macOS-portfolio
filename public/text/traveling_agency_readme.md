ADVENTURES
A website for a luxury safari and travel agency
================================================================

The brief was feel over feature count. Adventures is image-led,
restrained in its typography, and built so nothing stands
between the visitor and the destination.


LINKS
-----
Live site  : REPLACE_WITH_ADVENTURES_LIVE_URL
Source code: https://github.com/Royweru/adventures-travel-luxury
Demo video : open the Adventures folder in Projects


TECH STACK
----------
Next.js, TypeScript


RUN IT LOCALLY
--------------
git clone https://github.com/Royweru/adventures-travel-luxury.git
cd adventures-travel-luxury
npm install
npm run dev

Then open http://localhost:3000
