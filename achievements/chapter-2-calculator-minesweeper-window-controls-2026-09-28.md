# Calculator and Minesweeper window controls — 2026-09-28

Browser-verified common window interactions for Calculator and Minesweeper in the existing Weru 97 QA tab: title-bar drag, east-edge resize, southeast-corner resize, minimize/taskbar restore, maximize/restore, and title-bar close. Both close actions removed the window and taskbar entry. Minesweeper was closed without playing the board.

The maximized Minesweeper surface is mostly empty because the compact board stays at the upper-left. Keyboard/context-menu/touch behavior and the complete per-app matrix remain unverified; Phase 3 remains partial. Details: `plans/weru97-calculator-minesweeper-window-controls-2026-09-28.md`.
