# Chapter 2 Achievement — Outlook Express Live Window Controls

**Date:** 2026-09-27  
**Scope:** Chapter 2, Phase 3 — Common window controls

Using the browser extension in one existing QA tab, opened Outlook Express from its desktop shortcut, confirmed the expected recipient, dragged the window, widened it using the southeast resize handle, and closed it with the title-bar X. The window stayed within the desktop/taskbar boundary. No message was composed or sent.

The live check is limited to Outlook Express in the `localhost:3001` development origin; it does not complete the all-app control matrix or establish deployed parity. Overall Phase 3 remains partial.
