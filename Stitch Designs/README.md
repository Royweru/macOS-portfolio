# Weru 97 Stitch Designs

This directory stores raw Stitch HTML, previews, metadata, and implementation notes.

Raw Stitch artifacts must remain unchanged. React/CSS implementations belong in `src/`; this directory is the source-reference archive only.

Project: `Retro Windows 97 Design System`

Project ID: `2030522406260678629`

The supplied screen IDs and their classifications are tracked in `src/data/stitch-screen-manifest.ts`, `plans/stitch-screen-conversion.md`, and `tasks_list_windows97_upgrade.md`.

The current archive contains twelve local HTML references under `html/`, including the Stitch ZIP exports fetched on 2026-09-22 for the System Dialogs screen and the alternate Dual Explorer variant. One documented reference does not have a separate local HTML artifact yet: the second system-dialog variant. It remains marked `derived-missing-source` in the manifest and is implemented from the Weru 97 blueprint until its source artifact is supplied.
