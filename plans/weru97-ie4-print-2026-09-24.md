# Weru 97 IE4 Page Printing

## Goal

Make the visible IE4 Print toolbar button useful while ensuring browser print output contains the current IE page only—not the Weru desktop, taskbar, window chrome, or other open applications.

## Implementation

- Clone only the rendered `.win97-browser-page` into a temporary print surface attached directly to `document.body`.
- Add print-only CSS that hides the OS application tree and expands the cloned page for paper output.
- Invoke `window.print()` synchronously from the toolbar click so browser user activation is preserved.
- Remove the temporary surface after `afterprint`, when the IE window unmounts, or before a subsequent print attempt.
- Keep actual print-dialog appearance and physical/PDF output as manual browser verification; do not claim those without a live print preview.
